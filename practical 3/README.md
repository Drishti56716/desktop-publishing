## Objective

To design a clean, professional **promotional flyer** for a tuition centre using only **colour blocks, typography and alignment** in Photoshop. This practises layout, text hierarchy and balanced composition without needing any photographs.

## About the Design

The flyer for **"Shine High Classes"** is split into two parts:

| Section | Content | Style |
|---|---|---|
| **Top block** (about 70% of the height) | Small heading "TUITION CLASSES", large title "SHINE HIGH CLASSES" and a short divider line | Deep navy background (approx. `#14295B`) with white text |
| **Bottom block** (about 30% of the height) | "Contact: 844507xxxx" and the address (Old Tihri Vihar, Near Ram Chowk, Haridwar, Uttarakhand) | White background with navy text |

The phone number is partly hidden (`xxxx`) in the original design. Replace it with the real number before printing or sharing.

## Design Choices

- **Two-colour palette:** navy and white give strong contrast, so the text stays easy to read. Navy also looks trustworthy and academic.
- **Clear text hierarchy:**
  1. Brand name: very large, bold, white capitals
  2. Category label: small, widely spaced capitals above the name
  3. Contact details: medium bold navy text
  4. Address: smaller bold navy text
- **Centre alignment:** every element is centred, so the layout feels balanced and formal.
- **Divider line:** a short white bar under the title separates the brand from the lower section and adds a finishing touch.
- **Generous spacing:** plenty of empty space around the text keeps the flyer uncluttered.
- **Typeface:** a geometric sans-serif in the style of Montserrat (bold for the title and details, medium with wide tracking for "TUITION CLASSES").

## Tools and Features Used

- **Rectangle Tool (`U`):** draws the navy top block (or a Fill on a new layer)
- **Horizontal Type Tool (`T`):** all headings and details
- **Character panel:** font, size, weight and **tracking** (letter spacing)
- **Paragraph panel:** centre alignment
- **Align and Distribute:** centres each layer on the canvas
- **Layers panel:** separate, named layers for every element
- **Shape layer:** the small divider bar

## Steps to Recreate

1. **Create the document:** `File > New`, portrait, for example 800 × 1000 px, RGB, 72 ppi (or a print size such as A5 at 300 ppi).
2. **Fill the background white.**
3. **Draw the navy block:** use the Rectangle Tool to cover the top 70% of the canvas. Set the fill to approximately `#14295B`.
4. **Add the small heading:** type `TUITION CLASSES` in white. Reduce the size and increase *Tracking* (about 300 to 400) for the spaced-out look.
5. **Add the main title:** type `SHINE HIGH CLASSES` on three lines in large bold white capitals. Centre-align it and tighten the *Leading* slightly.
6. **Add the divider:** draw a short, thin white rectangle below the title and centre it.
7. **Add the contact details:** on the white section, type `Contact: 844507xxxx` in bold navy.
8. **Add the address:** type the address on three centred lines in a smaller bold navy size.
9. **Align everything:** select the layers and use *Align Horizontal Centres* to line them up with the canvas.
10. **Rename the layers** and group related ones.
11. **Save and export:**
    - `File > Save As` → `.psd` to keep the layers.
    - `File > Export > Export As` → `.png` or `.jpg` for sharing, or `.pdf` for printing.

## Suggested Layer Structure

```
Address                (Type)
Contact                (Type)
Divider Line           (Shape)
Title - SHINE HIGH CLASSES (Type)
Heading - TUITION CLASSES  (Type)
Navy Block             (Shape)
Background             (White fill)
```

## Possible Improvements

- Add a subtle **Drop Shadow** or **Stroke** layer style to the title for extra depth.
- Add a small **logo or icon**, such as a star or book, above the heading.
- Add a line listing subjects or classes offered, plus timings.
- Add a thin gold or sky-blue accent line for extra colour.

## Learning Outcomes

- Learned to build a layout using **shape layers and colour blocks**.
- Understood **typographic hierarchy**: size, weight and spacing guide the reader's eye.
- Practised **alignment and spacing** with the Align and Distribute tools.
- Learned how **contrast** (white on navy) improves readability.
- Learned to save a layered `.psd` and export it in different formats.
