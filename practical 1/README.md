**Software:** Adobe Photoshop

## Objective

To get familiar with the Photoshop workspace by creating a simple design that uses the **shape tools**, **fill colours** and the **Type tool** on a clean canvas.

## What the Design Contains

| Element | Shape Tool Used | Colour (approx.) | Notes |
|---|---|---|---|
| Circle | Ellipse Tool (`U`), hold `Shift` for a perfect circle | Blue `#2F7BE0` | Placed on the left side |
| Triangle | Polygon Tool with 3 sides | Pink `#FF69B4` | Placed at the top right |
| Rounded rectangle | Rounded Rectangle Tool, corner radius about 40 px | Yellow `#FFCB2B` | Placed at the bottom right |
| Heading | Horizontal Type Tool (`T`) | Dark grey | "PHOTOSHOP PRACTICAL 1" in spaced capital letters |
| Name and course | Horizontal Type Tool (`T`) | Dark grey | Centred at the bottom; "Drishti" is bold |

The background is a plain light-grey/white fill, so the three bright shapes stand out.

## Tools and Features Used

- **Shape tools:** Ellipse, Polygon and Rounded Rectangle
- **Properties panel:** to set fill colour, size and corner radius
- **Type tool + Character panel:** font, size, tracking (letter spacing) and bold weight
- **Layers panel:** each shape and text item sits on its own layer
- **Align and Distribute / Move tool (`V`):** to position and balance the elements

## Steps to Recreate

1. **Create a new document:** `File > New`, landscape, RGB colour mode, 72 ppi.
2. **Fill the background:** set a very light grey (`#F5F5F5`) and fill the Background layer (`Alt + Backspace`).
3. **Draw the circle:** choose the Ellipse Tool, hold `Shift` and drag on the left. Set the fill to blue.
4. **Draw the triangle:** choose the Polygon Tool, set *Sides* to `3`, drag on the upper right and set the fill to pink.
5. **Draw the rounded rectangle:** choose the Rounded Rectangle Tool, drag on the lower right, raise the *Corner Radius* in the Properties panel and set the fill to yellow.
6. **Add the heading:** use the Type Tool to type `PHOTOSHOP PRACTICAL 1` at the top left. Increase *Tracking* in the Character panel for the spaced-out look.
7. **Add the name and course:** type `Name: Drishti` and `Course: BCA` as centred text at the bottom. Make "Drishti" bold.
8. **Rename the layers:** for example `Blue Circle`, `Pink Triangle`, `Yellow Rounded Rectangle`, `Heading` and `Name and Course`.
9. **Align everything:** use the Move tool and the alignment options so the spacing looks even.
10. **Save and export:**
    - `File > Save As` → `.psd` to keep the layers.
    - `File > Export > Export As` → `.png` or `.jpg` for the final image.

## Suggested Layer Structure

```
Name and Course        (Type)
Heading                (Type)
Yellow Rounded Rectangle (Shape)
Pink Triangle          (Shape)
Blue Circle            (Shape)
Background             (Fill)
```

## Learning Outcomes

- Understood the Photoshop interface: toolbar, options bar, Properties panel and Layers panel.
- Learned to draw vector shapes and change their fill colour.
- Learned basic text formatting, including font, weight, alignment and letter spacing.
- Learned why layers matter: each element can be moved or edited without affecting the others.
- Practised simple composition: balance, spacing and colour contrast.
